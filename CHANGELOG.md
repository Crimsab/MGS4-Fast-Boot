# Changelog

All notable changes to MGS4 Fast Boot are documented here.

## 1.0.0 - 2026-09-01

- Preserve the official launcher's saved region, language, display, input, and Steam settings.
- Append only the verified `--skip-to-main-menu` flag to the final native game request.
- Lock activation to Steam buildid `24921893` and verified launcher/game hashes.
- Provide Shift bypass, INI controls, hash-checked installation, and reversible uninstall.
- Add reproducible source builds, deterministic release archives, and automated GitHub Releases.
